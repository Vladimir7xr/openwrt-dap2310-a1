# OpenWrt Support for D-Link DAP-2310 Rev. A1

Custom configuration files to build OpenWrt for the D-Link DAP-2310 A1 access point.

## 📌 Device Specifications
* **SoC:** Atheros AR7242
* **Flash:** 8 MB
* **RAM:** 32 MB

## 📂 File Descriptions
* `*.dts` — Device Tree Source file.
* `generic.mk` — Image build profile.
